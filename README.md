# 3D First-Person Platformer (Prototype)

A 3D platformer prototype developed in **Unity (C#)**. Focused on level design, environment lighting, terrain sculpting, and first-person character navigation.

## ⚙️ Key Features & Mechanics
* **Environment & Level Design:** Built a 3D level from scratch using Unity Terrain, foliage tools, custom materials, and lighting setup.
* **First-Person Movement:** Integrated and tuned a First-Person Controller to test level geometry, jump distances, scale, and obstacle navigation.

## 🎮 Controls
* **WASD:** Move character
* **Mouse:** Look around
* **Space:** Jump
* **Shift:** Sprint 


## 📂 Project Structure (Where to look)
The core C# scripts are located in `Assets/Scripts/`:
* `PlayerMovement.cs` — handles first-person movement, jumping, and gravity.
* `CameraLook.cs` — mouse look controls and camera rotation.
